# Контекстный русский [KP]

[KP] — язык описания намерений для больших языковых моделей (LLM). Модель выполняет роль компилятора. Дисциплина изучает формулировку требований на русском языке для предсказуемого результата.

- **Тип:** прикладная дисциплина
- **Область:** инженерия ПО, вычислительная лингвистика, управление AI-продуктами
- **Дата основания:** 16 октября 2026
- **Предмет:** описание намерений для LLM
- **Сайт:** https://aictx.ru
- **Telegram-канал:** https://t.me/context_russian

## Предмет дисциплины

- формализация требований;
- архитектура контекстного окна;
- семантика русского языка при работе с моделью;
- верификация результата.

[KP] не является промпт-инжинирингом. Промпт-инжиниринг подбирает фразу для разового ответа. [KP] проектирует среду для предсказуемого и воспроизводимого результата.
